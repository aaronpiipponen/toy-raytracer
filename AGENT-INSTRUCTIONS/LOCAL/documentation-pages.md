The toy raytracer's documentation is `README.md`, `docs/requirements.md` and the pages under `docs/`: `rendering.md`, `geometry.md`, `materials.md` and `image-output.md` as technical pages, `running.md` as a setup page and `architecture.md` as a developer page. Diagrams live in `docs/diagrams/` and the logo in `docs/brand/logo.svg`. A phase that changes the command line updates the usage in `README.md` and `docs/running.md`, and a phase that changes behaviour updates the page that describes it. There is no documentation index, screenshot set, published documentation or experiment report.
