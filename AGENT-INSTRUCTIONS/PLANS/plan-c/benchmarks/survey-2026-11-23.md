## Out-of-scope observations

Not plan-c findings; reported with the evidence already in hand and not investigated further.

1. Dead-code suppressions await other plans: `#[allow(dead_code)]` on `mod rng` (`src/main.rs:8`),
   on `HitRecord::point` (`src/hittable.rs:10`) and on `Vec3::cross` (`src/vec3.rs:21`). The
   materials and geometry plans consume them; the release should confirm each marker disappears
   once its plan lands.
2. Test-time progress noise: both render tests now write the progress line to the test harness's
   standard error. The progress phase accepted this explicitly, so it is a recorded decision.
3. `--samples` currently averages identical rays and changes no byte (`src/main.rs:54-59`). This is
   the frozen command-line contract; jitter and the rest of requirement 5 belong to the materials
   plan.
4. Merge risk on gamma: plan-a's landed contract freezes gamma 2 inside `to_byte`, while plan-c's
   `to_byte` is linear (`src/main.rs:67-69`). A merge over plan-c's `src/main.rs` must preserve the
   gamma correction.
